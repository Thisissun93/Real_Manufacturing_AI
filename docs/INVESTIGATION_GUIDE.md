## 이번 변경

기존 Streamlit 시작 파일 `src/dashboard/app.py`를 유지하고 첫 화면을 제조 이력 조사로 변경했습니다. 기존 통계·ML 기능은 왼쪽 ‘기존 통계·ML (학습용)’에서 접근합니다. 기존 데이터·모델을 삭제하거나 다시 학습하지 않습니다.

1. 약액 탱크의 전체 교체 구간과 보충 이벤트를 LOT 이력에 연결합니다.
2. 동일 모델의 보충 전후 LOT를 비교하고 Cu 시편 지수와 검사 PCS 기반 불량률을 표시합니다.
3. Panel → Quad → Unit, 층·면·검사 회차별 대표 불량 위치를 표시합니다.
4. 같은 자재·탱크 교체 구간·설비를 공유한 LOT와 정상 비교군을 보여줍니다.
5. 원인 후보별 이탈 근거, 대조할 정상 LOT, 부족한 기록, 확인시험을 제시합니다.
6. 검토 이력을 추가하고 백업·복원하거나 편집 가능한 HTML 보고서를 저장합니다.

공개 기본 예시는 보충 24 LOT, 전체 교체 48 LOT, 공회전 12분, 통과 시간 36/54분으로 독립 설계했습니다. 실제 사내 주기·온도표를 재현하지 않습니다. 모델별 12/17 mm 치수는 사용자가 제안한 공개 배치 예시입니다. 후속 공정은 조사 연결 시연을 위한 축약 경로이며 실제 제조 순서 확정본이 아닙니다.

## 해석 기준

- 불량률 = 선택한 층·면·검사 회차의 불량 Unit PCS / 검사 Unit PCS. 다른 층·면을 합쳐 고유 제품 수처럼 보고하지 않습니다.
- 다른 대표 코드로 판정된 유닛은 ABF 동반 여부 미확인입니다. ABF 음성 학습 레이블로 만들지 않습니다.
- AOI PASS는 정상 비교군 선정 조건이며 잠재 계면 결함 부재의 보증이 아닙니다.
- 원인 후보는 사전 규칙으로 산출합니다. 외부 생성형 AI 호출이나 원인 확률 생성이 없습니다.
- 보충 전후 비교는 관찰 비교입니다. 자재 교체·공정 변화·시간 경향을 분리한 인과 분석이나 유의성 검정이 아닙니다.
- 조회 시각 이후에 확정된 공정 기록·AOI·단면 결과는 제외합니다. 기본값은 마지막 AOI 시각입니다.
- 상관관계·예측 중요도·기준 이탈만으로 근본 원인을 확정하지 않습니다. 실제 조치 결과는 사용자가 입력해야 합니다.

## 저장과 검토 이력

검토 기록은 현재 브라우저 세션에만 존재합니다. 새로고침·서버 재시작 전에 ‘검토 이력 백업 JSON’을 저장하세요. 복원은 체크섬 손상과 같은 ID의 내용 충돌을 거부하며 동일 기록은 중복 추가하지 않습니다. 체크섬은 손상 탐지용이며 전자서명이나 위변조 방지 인증이 아닙니다.

보고서에는 LOT·층·면·회차·조회 시각·데이터 해시가 일치하는 검토만 자동 삽입합니다. 내려받은 HTML 본문은 편집 가능하며 ‘수정본 HTML 저장’으로 수정 내용을 보존합니다. 원본 데이터에는 수정 내용이 역반영되지 않습니다. PDF는 인쇄 기능을 사용합니다.

## 데이터 형식

`samples/investigation/demo.json`을 예시로 사용합니다. 120 LOT, 공정 1,200행, AOI 637,440 유닛 검사 기록이며 테이블별 행 수가 달라도 LOT와 기록 ID로 연결합니다.

|테이블|핵심 필드 및 의미|
|---|---|
|lots|id, model, recipe, material, start/end, expected_units: 한 층·면·회차 예상 검사 수|
|runs|id, lot, step, equipment, start/end, available_at, parameters; CZ에는 tank/cycle/replacement/refill과 카운터|
|tank_events|id, tank, type(REPLACE/REFILL), cycle, start, dosing_end, end(공회전 포함 완료), available_at|
|aoi|id, lot, panel, quad(1~4), unit, layer, side, inspection, code, time, x/y(Quad내 0~1)|
|confirmations|검사 유닛 연결 키, method, time, abf_confirmed, interface, selection|
|parameters|value(null 허용), unit, lower/upper/target(null 허용), basis|

신규 예시는 `inspection_groups`에 검사 범위별 전체 유닛의 대표 코드 배열을 저장합니다. 배열은 Quad A→D, 각 Quad의 행 우선 Unit 순서이며 PASS도 명시적으로 저장합니다. `locations`에는 대표 불량의 유닛 내부 0~1 좌표가 있습니다. 이전 `aoi` 개별 행 형식도 지원하되 동일 검사 범위의 중복 저장은 거부합니다. 평가 정답은 결함이 있는 합성 유닛만 별도 기록하므로 정답 파일 행 수를 검사 분모로 사용하지 않습니다.

온도 `profile`은 경과 초 배열, 측정 온도 배열, 기준 온도 배열과 Zone 구간으로 구성됩니다. 시뮬레이션 측정값은 실제 공장 측정값이 아닙니다. Zone 경계는 예시 공정시간을 균등 분할한 값입니다.

필수 연결 키가 없거나 중복 검사·존재하지 않는 LOT·시간대 없는 시각·설비 처리 중복·잘못된 탱크 이벤트 연결이면 입력을 거부합니다. 일반 측정 결측은 0으로 채우지 않습니다. JSON `null`을 사용합니다. 기존 CSV/모델 형식은 그대로 보존되며 새 조사 JSON과 자동으로 혼합하지 않습니다.

## 공모전 전 다음 검증

1. 본인이 시연 사례의 근거·대조군·확인시험 흐름을 검토하고 기대 결과를 먼저 작성합니다.
2. 독립 시나리오로 원인 후보 누락, 잘못된 우선순위, 연결 누락을 평가합니다. 합성 정답은 엔진 입력에서 계속 분리합니다.
3. 수작업 조사와 프로그램 사용의 소요 시간·근거 누락 수를 동일 과제로 비교합니다.
4. 영구 DB·사용자 인증·감사 이력이 필요할 때 별도 설계합니다. 현재 세션 백업을 산업용 이력 관리로 주장하지 않습니다.
5. 실제 현장 데이터가 확보되면 공개 허용 범위와 측정 시스템을 먼저 확인한 뒤 시간·설비·자재 단위 외부 검증을 추가합니다.


## 화면 개선 추가 안내

- MODEL-A: 12×12 mm, 20행×20열 = Quad당 400 PCS, Panel당 1,600 PCS.
- MODEL-B: 17×17 mm, 14행×14열 = Quad당 196 PCS, Panel당 784 PCS.
- 위 수량은 가상의 배열이며 실제 패널 유효 면적·가공 여유를 검증한 생산 수량은 아닙니다.
- Quad A/B/C/D를 선택한 뒤 유닛 사각형을 클릭합니다. PASS/FAIL은 대표 코드 유무로 표시합니다. FAIL 유닛의 상세 그래프는 저장된 최초 대표 불량 좌표만 mm로 표시합니다. 위치 기록이 없으면 자동 추정하지 않습니다.
- 온도 곡선은 1초 간격입니다. Y축 °C, X축 경과 분, 세로 점선/상단 표시는 Zone, 툴팁은 경과 초를 보여줍니다. 휠/드래그로 확대·이동하며 더블클릭으로 초기화합니다.
- 공정시간은 동일 모델·개정의 AOI PASS LOT 중앙값과 비교하고 분/% 차이, 관측 최소·최대, 비교 LOT 수를 보여줍니다. 3 LOT 미만이면 ‘비교군 부족’입니다. 정상 관측 범위를 관리 규격으로 해석하지 않습니다.
- 순수 저항 하한 이탈 사례를 약액 상태 변화 시연에 포함했습니다. 상한은 설정하지 않았습니다.
- 최종 보고서는 한글 표·온도 그래프·요약으로 구성합니다. 프로그래밍 코드, JSON 자료 구조, 개발용 명령은 본문에 표시하지 않습니다.
