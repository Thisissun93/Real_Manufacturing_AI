# 종합 분석·공개 정보 정리

실제 제조사와 장비 제품군 식별정보를 화면, 실행 코드 및 전달 문서에서 제거했습니다. 기존 개인 보관본은 삭제하지 않았습니다. 공개된 Git 이력 전체를 정리했다는 의미가 아닙니다. 이번에는 GitHub에 push하거나 사이트를 재배포하지 않았습니다.

종합 분석은 ABF 최초 대표 코드 PCS를 집계하고 같은 모델·개정·검사 범위에서 공정 인자와의 관찰 관계를 계산합니다. Random Forest/SHAP는 시간순 분할, 검사 결과 확정 시각에 따른 학습 제외, 학습 구간 내 결측 대체를 사용합니다. 최신 결과는 합성 자료 검증이며 실제 원인 기여도는 아닙니다.

초기 40% 이후 3개 시간 구간 검증. 단순 평균 예측 대비 MAE 10% 이상 개선, 검증 ABF 양성/음성 LOT 각각 3개 이상일 때만 모델 설명을 점검 우선순위 보조 근거로 채택합니다. 수량이 적은 합성 검증의 한계를 표시합니다.

예방보전: 최근 기준 이탈(P1), 8 LOT 추세의 향후 3 LOT 접근 시나리오(P2), 이탈과 불량의 반복 동반 기록(P3). 교체 수명 근거가 없는 부품의 RUL을 만들지 않습니다.

원본 운영자료, SQLite, Library 본문/도면은 배포 압축에 포함하지 않습니다. `instance/`를 Git에서 제외합니다. 전체 프로젝트의 사내정보 적합성을 자동 판정하지는 않습니다.
