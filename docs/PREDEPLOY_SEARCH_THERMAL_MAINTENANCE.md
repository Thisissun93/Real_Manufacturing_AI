# 최종 배포 전 검색·온도·설비 점검 보완

## 사용
- 사이드바 LOT ID 직접 검색에 전체 ID 입력 후 검색. 앞뒤 공백·영문 대소문자 무시. 해당 모델까지 자동 전환. 미일치 시 기존 조회 보존.
- DEMO-0046: Cure 고온 구간, 고온 Baking Hot Zone 저온 및 Cooling Zone 고온 노출 시연.
- 파랑 음영은 제품 기준보다 낮은 구간, 주황은 높은 구간. Zone별 노출 시간·최저/최고 편차를 표시.
- 기본 ±4°C는 기존 시연용 제품 프로파일 허용 편차. 양산 규격이나 경화 완료 기준이 아님. 입력 profile.tolerance_c가 없으면 이탈 판정 보류.
- 제품은 설정 온도에 즉시 도달하지 않음. 설정값에 단순 비교하여 정상 승온·냉각을 이탈로 오판하지 않도록 별도 제품 기준 곡선과 비교.
- 초 단위 샘플 값을 다음 샘플까지 유지하는 방식으로 구간별 노출 시간을 합산. 최종 샘플에 추가 시간을 부여하지 않음.
- 고온 Baking: 모델 A 190°C / 모델 B 200°C Hot Zone 90분, Cooling Zone 30°C 30분. 1초 간격 7,201개 기록. 온도는 사용자 제공 시연 조건.
- 과경화·미경화는 자동 확정하지 않음. 제품/자재 경화 사양과 추가 분석 결과가 필요.
- 약액·공정 측정 표에서 기준 이탈은 붉은 배경, 결측은 노란 배경. 정상 LOT 시간 비교 강조 유지.
- 현재 조사 데이터 다운로드는 압축 공백 없는 JSON으로 제공하며, 내려받은 자료를 35 MB 제한 내에서 다시 불러올 수 있음.

## 설비 점검
설비·부품 목록은 공정 기능으로만 분류하며 실제 제조사·형식은 공개 데이터에 포함하지 않습니다.
공개 제품 소개를 개별 설치 장비의 유지보수 매뉴얼이나 승인 사양으로 간주하지 않음.
- CZ: 카트리지 필터, Hot dry HEPA, 롤러 오링, 부싱·헬리컬 기어, 제품 감지 센서, 디지털 공압·수압·온도·농도 센서, 피커 패드, 오리발형 노즐.
- ABF 밀착: SUS Plate, Rubber Plate, 온도 센서, 정밀 위치 센서.
- Pre-bake/Cure: 행거, 온도 센서, HEPA, SUS 타공판, 기판 낙하 센서, 냉각·히팅 블로워, 칠러, 히터 점검.
- 고온 Baking: Window Frame, 온도 센서, HEPA, 기판 낙하 센서, 냉각·히팅 블로워, 롤러 샤프트·오링, 지지 링크발, 히터 점검.
점검 초안은 매교대 기능/상태 확인, 주간 오염/마모 확인, 월간 정밀·성능 대조 중심. 제조사가 보증한 수명이나 통상 교체주기로 주장하지 않음.
교체는 차압·여과 성능·손상·마모·공차·반복정밀도·교정 오차 등 부품별 조건에 따라 검토. 실제 공차나 임계값 미등록이면 임의 숫자로 판단하지 않음.
권장 교체 수명은 공개 자료에서 확정하지 못했으므로 자동 생성하지 않음. 재질·약액·온도·사용량에 따라 달라지는 부품에 일률적으로 3개월/1년을 적용하지 않음.
PDF는 우선 확인 후보에 해당하는 점검 제안을 포함하며, 화면에서는 다른 후보와 설비별 전체 점검 근거도 열람 가능.

## 정비 이력 입력
사이드바 '설비 정비 이력 가져오기'에서 JSON 목록(2 MB 이하)을 불러옴. 기존 데이터의 maintenance 필드도 지원.
각 항목: equipment(설비 ID), component(화면의 점검 대상 이름과 정확히 일치), available_at(기록이 확인 가능해진 시각, 시간대 포함), source(적용 매뉴얼/승인 기준 식별), due_at(기한, 선택), used_hours(기록 시점 누적시간), limit_hours(허용시간), warning_days / warning_hours(임박 알림 기준, 선택).
source가 없으면 수명 기준 미등록. 해당 LOT 공정 종료 이후 확인된 정비 기록은 과거 원인 판단에 사용하지 않음.
달력 기한과 사용시간은 별개로 평가. 정비 기한 초과만으로 고장이나 불량 원인으로 확정하지 않음.

## 공개 근거와 적용 한계 (2026-09-25 확인)
- Despatch 전기 오븐 PM: https://www.despatch.com/pdfs/PM-TAD-TFD-Elect.pdf
  센서 대조·블로워·히터·기류 점검 항목 참고. 다른 제조사의 수치·주기를 그대로 ABF 설비에 적용하지 않음.
- Watlow 교정: https://support.watlow.com/epm/en-us/Content/E-Maintenance/Calibrating_IO.htm
  센서/배선/설치 변화와 기준 대조 항목 참고.
- Camfil HEPA FAQ: https://www.camfil.com/damdocuments/29914/29840/faq-hepas-and-ulpas-technical-bulletin.pdf
  운전조건에 따른 수명·차압 기반 관리 참고. 자료는 Camfil 제품에 한정됨. 일반 공조용 필터의 수명·차압 배수를 190~200°C 건조로에 자동 적용하지 않음. 실제 내열 필터 모델 확인 필요.
- 사용자 Cleaning 프로젝트 README: https://github.com/Thisissun93/semiconductor_wet_cleaning_system
  이상 신호 → 원인 후보 → 조치 추천의 화면 흐름 참고.

## 검증 및 배포
최종 전체 자동 테스트 68개 통과.
기존 원인/반례 9개 × seed 3개 = 27/27 통과. 부품 목록 변경과 화면 동작을 포함해 재검증.
PDF를 이미지로 렌더링해 Zone 음영·표·한글·페이지 잘림 확인.
ZIP은 기존 프로젝트 루트에 덮어쓰는 업데이트 패키지. 기존 검토 JSON과 instance/custody.sqlite3를 먼저 백업.
기존 Git/data/models는 삭제하지 않으며 원격 배포는 수행하지 않음.
